# 人口学变量录入（@local/demographic-coder）

一个装在 DSH Web 界面里的人口学数据工作台：把 Excel / Word 问卷导进来，按分类变量填空录入纸质问卷，按常见人口学编码导出 CSV。侧边栏点「人口学录入」图标进入，主面板分四页：**录入 / 数据 / 编码 / 导入**。

## 三个要求的落点

1. **外部导入 Excel / Word，并自动读取分类**
   - `.xlsx`：读工作簿的全部工作表、共享字符串与内联字符串；自动判断表头行；每列自动判断「分类 / 数值 / 文本」。
   - `.docx`：把文档里的表格读成「一行一份问卷」；没有表格时，把 `性别：男`、`学历：硕士` 这类段落读成一份问卷。
   - `.csv` / `.txt`：自动识别逗号或制表符分隔、带引号的单元格、BOM。
   - 列名匹配内置词典（"您的性别" 也能认成性别）；列里出现的取值自动登记到该列的编码表。
   - 如果工作簿里另有一张 `变量 / 编码 / 标签` 三列的编码表，会自动识别并套用到同名变量上（优先于内置词典）。
2. **填空式录入，便于纸质问卷**
   - 「录入」页按列生成填空项，Tab 逐项切换，最后一格回车即保存并跳到下一份；被试编号自动递增，也可手改（纸质问卷从 101 开始、或直接填 11002 这类编号都可以）。
   - 输入"男"或直接输入"1"都行，保存时统一成"男"，编码在导出时换算；下方实时显示「编码预览」和最近三条记录，可撤销上一份。
   - 与已有记录完全相同的输入会先拦一次，再按一次保存才写入，防止连按回车录重。
3. **基本人口学变量的简单编码**
   - 内置词典：性别（男=1、女=2）、是否右利手（是=1、否=2）、教育程度（1–7）、受教育年限、婚姻状况、户口性质、政治面貌、民族、是否独生子女、年级、生源地、出生日期、出生地（长期成长地）、当前居住地、填表日期、通用是否（是=1、否=2）。
   - 2026-10-26 按《被试基本信息收集表》补齐：新增独立字段「最高学历」（1=高中及以下、2=本科、3=硕士、4=博士，与旧的 1–7 教育程度并存）、是否右利手、出生日期、受教育年限、出生地、当前居住地、填表日期；教育程度新增「高中及以下」「硕士研究生」「博士研究生」别名；婚姻状况新增 6＝恋爱；年级新增 9＝大五、10–13＝博一至博四。旧编码保持不变，已有数据不受影响。
   - 「编码」页按变量逐个列出观察到的取值，可改编码、开关编码、改类型、自动编码、加变量；留空的编码按词典自动匹配，手填的覆盖优先。
   - 导出时编码值优先，未匹配的保留原文；同时导出一份编码手册。

## 本实验基本信息收集表（2026-10-26 起）

`02_实验材料与问卷/被试基本信息收集表.docx` 是竖排表（一行一个项目），直接拖进来会被读成「项目 / 填写栏」两列，不适合当作答表。录入时请用「导入」页的模板 **本实验基本信息表**（12 个变量，已按词典配好类型与编码）：

性别、是否右利手、年龄、出生日期、受教育年限、最高学历（包含在读）、年级（若在读）、民族、出生地（长期成长地）、当前居住地、婚姻状态、填表日期。

填写约定：出生地 / 当前居住地按「地区-省-市」写（如 `内地-广东省-广州市`、`港澳-香港`、`海外-美国`），导出后可按前缀再拆；被试编号就是录入页右上角那一栏（自动递增、可手改），导出 CSV 的首列即「被试编号」。

## 导出

点顶部「保存CSV」写入「导入」页设置的文件夹（默认 `<工作区>/人口学变量`），会写三个文件：

| 文件 | 内容 |
| --- | --- |
| `<数据集名>.csv` | 首行 `被试编号` + 变量标签，编码后的数据，UTF-8 带 BOM（Excel 直接打开不乱码） |
| `<数据集名>_编码手册.csv` | 变量名、标签、类型、`男=1; 女=2` 形式的编码、缺失值 |
| `<数据集名>.json` | 同一份数据的快照（列定义 + 扁平记录），方便 agent / R / Python 再读 |

「下载CSV」只把数据 CSV 交给浏览器下载，不落工作区。当前数据集同时存在浏览器 localStorage，刷新和重启都在。

## 本机接口

Host 半边只做一件事：把三个导出文件写进你选的文件夹。

- `GET  /api/demographic-coder?action=status` → 默认文件夹
- `POST /api/demographic-coder` `{ action: 'save', payload: { name, dir, csv, codebook, json } }`
- `POST /api/demographic-coder` `{ action: 'reveal', payload: { dir, file } }` → 资源管理器定位

请求必须是同源并带 `x-demographic-coder: 1` 头，跨站页面无法伪造。解析全部在页面里完成，问卷内容不上传。

可选配置（`cordis.patch.yml` 的 `config`）：

```yaml
root: 'C:/Users/me/论文/数据'   # 固定导出根目录，并限制只能写在这棵树里
```
